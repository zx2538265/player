# BIGBANG 台北場群友清單

獨立本機網站，不依賴 player 的程式、npm 或第三方 Python 套件。需 Python 3.10 以上。

雙擊 `start.cmd`，再開啟 http://127.0.0.1:8766 。關閉命令視窗即停止。

網站依指定 Google 試算表「完整名單」的日期欄自動建立日期清單，不固定為三天。不去重。筆數是來源列數，不代表不重複人數。網站及 JSON 只保留日期、群友及來源列號。

初始資料由完整 XLSX 匯出擷取，保存在 `data/seats.json`；原始匯出保存在 `data/source.xlsx`。每次開啟或重新整理網頁，先顯示上次名單，再自動從 Google 試算表抓取最新資料；也可以點「重新抓取名單」手動更新。經本機伺服器讀取指定 gid 的 CSV，驗證欄位及每列日期成功後才原子替換。下載或資料驗證失敗會保留舊名單並顯示提示。更新需要網路及試算表允許讀取；頁面持續開啟時不會背景輪詢，並非 Google 推播同步。

僅綁定 127.0.0.1；未提供登入及公開部署。群友資料在 .gitignore 排除，不要將 data 資料夾公開。Google Fonts 只載入字型，字型不可用時採系統字型。參考海報只用於視覺方向，不作為活動日期資料來源。
